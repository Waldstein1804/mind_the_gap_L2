# Data and analysis codes for Mind the Gap

This repository has data and analysis codes for 'Mind the Gap: Temporal Dynamics of Turn Transitions in L2 Interviews'.

**mtg_sep26.csv** is a data file.

**MTG_sep2026_models** shows Bayesian models reported in the manuscript (Rmd/html).

**MTG_tables_figs_sep2026** shows codes for creating figures and tables (Rmd/html).
