# Data and analysis codes for Mind the Gap

This repository has data and analysis codes for 'Mind the Gap: Temporal Dynamics of Turn Transitions in L2 Interviews'.

**mtg_sep26.csv** is a data file.

**MTG_sep2026_models** shows Bayesian models reported in the manuscript (Rmd/html).

**MTG_tables_figs_sep2026** shows codes for creating figures and tables (Rmd/html).



# ICNALE data samples (Ishikawa, 2019, 2023)

Sample audiovisual segments and timing annotations are available online at https://plop-code.github.io/plew/examples/icnale_plew_demo/

Plew (Cangemi et al., in press) was used for sample curation. The sample data segments are presented by proficiency group (beginner, intermediate) and question type (polar, open). User can click each data point to display a segment of video, sound, and/or Praat annotation.


### References

Cangemi, F., Sprague, L. & Same, F. (in press). Collaborative exploration of complex data landscapes with PLeW. Oral Archives Journal, 3.

Ishikawa, S. (2019). The ICNALE Spoken Dialogue: A new dataset for the study of Asian learners’ performance in L2 English interviews. English Teaching, 74(4), 153–177.

Ishikawa, S. (2023). The ICNALE guide. Routledge.
